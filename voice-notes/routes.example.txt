# Voice Router — routing rules
# Start a recording with the topic, pause, then talk:
#   "Session, ..."            -> your Session notes folder
#   "Sermon, Advent, ..."     -> Sermons/Advent   (subtopic folder created if new)
#   "Presbytery, ..."         -> Voice Notes/Presbytery   (brand-new topic: folder created)
#
# Format:  keywords | folder inside Google Drive | sub: where new subtopic folders go
#   Paths are relative to your Google Drive root as Finder shows it:
#     "My Drive/..."            = your own Drive
#     "Shared drives/*/..."     = any shared drive (the * matches the drive's name)
#   The first keyword on each line is the label used in the transcript's filename.
#   Add other spellings Whisper might use after commas (e.g. "women's, womens").
# New topics get added to the bottom of this file automatically.
# Edits take effect on the next recording. No restart needed.
#
